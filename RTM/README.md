Requirement Traceability Matrix (RTM)

This folder contains the Requirement Traceability Matrix prepared as part of my Manual Testing Portfolio.

Purpose

The RTM is used to map business requirements to their corresponding test scenarios and test cases.

Objectives

- Ensure all requirements are covered by test cases.
- Track testing coverage.
- Identify missing test cases.
- Maintain requirement-to-test-case traceability.

Project
Demo Web Shop

Testing Approach
Manual Functional Testing.
