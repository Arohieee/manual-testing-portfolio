# Manual Testing Portfolio

Project Overview

This project demonstrates my knowledge of manual software testing through test scenarios, test cases, defect documentation, and test execution.

Objectives

- Understand application requirements.
- Design positive and negative test cases.
- Execute test cases and record actual results.
- Identify, report, and retest defects.
- Document testing results.

Scope of Testing

- Functional Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Positive and Negative Testing

Project Deliverables

1. Test Scenarios and Test Cases
2. Bug Reports
3. Requirement Traceability Matrix (RTM)
4. Test Execution Results
5. Test Summary Report

Tools
- Microsoft Excel / Google Sheets
- GitHub
